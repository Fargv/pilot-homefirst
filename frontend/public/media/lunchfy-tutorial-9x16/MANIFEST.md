# Package Manifest

## Required Runtime

Any modern Chromium browser is enough to render the animation.

## Local Dependencies

None. The package has no npm dependency requirement for playback.

## Animation Timing

Full version:

- 0s-7s: Brand intro
- 7s-15s: Planning problem
- 15s-25s: Weekly planner
- 25s-34s: Recipe library
- 34s-43s: Shopping list
- 43s-50s: Household sharing
- 50s-54s: Final CTA

Teaser version:

- 0s-4s: Brand intro
- 4s-8s: Weekly planner
- 8s-12s: Shopping list
- 12s-15s: Final CTA

## Viewport

Use exactly 1080 x 1920 for the intended 9:16 render.

## Notes

The original `Lunchfy Tutorial 9x16.dc.html` referenced missing files:

- `support.js`
- `LunchfyScenes.jsx`

This package includes replacements and a new self-contained render path.
